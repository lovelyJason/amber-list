## 技术债务清单

### 高优先级

1. **Provider持久化集成**
   - 当前使用内存数据
   - 需要连接Drift数据库

2. **错误处理**
   - 添加全局错误处理
   - 用户友好的错误提示

3. **加载状态**
   - 异步操作加载指示
   - 骨架屏

### 中优先级

1. **单元测试**
   - Provider测试
   - Widget测试
   - 集成测试

2. **性能优化**
   - 列表虚拟化（大量任务）
   - 图片缓存
   - 懒加载

3. **代码重构**
   - 抽取通用组件
   - 减少重复代码

### 低优先级

1. **国际化**
   - 多语言支持
   - 日期格式本地化

2. **主题切换**
   - 暗色模式
   - 自定义主题色

3. **无障碍**
   - 屏幕阅读器支持
   - 高对比度模式

## 贡献指南

### 开发流程

1. Fork 项目
2. 创建功能分支：`git checkout -b feature/xxx`
3. 提交更改：`git commit -m 'Add xxx'`
4. 推送分支：`git push origin feature/xxx`
5. 创建 Pull Request

### 代码规范

- 遵循 [Effective Dart](https://dart.dev/guides/language/effective-dart)
- 运行 `flutter analyze` 确保无警告
- 新功能需要添加测试

### 提交信息格式

```
<type>(<scope>): <subject>

<body>

<footer>
```

类型：
- `feat`: 新功能
- `fix`: Bug修复
- `docs`: 文档更新
- `style`: 代码格式
- `refactor`: 重构
- `test`: 测试
- `chore`: 构建/工具
