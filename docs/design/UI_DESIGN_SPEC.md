# 琥珀清单 UI 设计规范

## 品牌定位

**琥珀清单** - 封存万物，历久弥新

琥珀作为一种天然宝石，能够完美保存数百万年前的生物。我们希望这款应用也能像琥珀一样，帮助用户"封存"每一个想法、任务和灵感，让它们历久弥新，永不遗忘。

## 布局规范

### 整体结构（四栏布局）

```
┌─────────────────────────────────────────────────────────────────┐
│                        顶部栏 (56px) - 可选                      │
├────┬────────┬─────────────────────────┬─────────────────────────┤
│    │        │                         │                         │
│ 窄 │  清单  │       主内容区          │      详情面板           │
│ 侧 │  侧边  │    (任务列表/日历/      │    (可收起)             │
│ 边 │  栏    │     笔记网格)           │                         │
│ 栏 │        │                         │                         │
│    │ 220px  │        flex             │       320px             │
│56px│        │                         │                         │
│    │        │                         │                         │
└────┴────────┴─────────────────────────┴─────────────────────────┘
```

### 尺寸常量

| 元素 | 尺寸 | 变量名 |
|------|------|--------|
| 窄侧边栏宽度 | 56px | `narrowSidebarWidth` |
| 清单侧边栏宽度 | 220px | `listSidebarWidth` |
| 详情面板宽度 | 320px | `detailPanelWidth` |
| 顶部栏高度 | 56px | `topBarHeight` |

### 间距系统

| 级别 | 尺寸 | 变量名 | 用途 |
|------|------|--------|------|
| xs | 4px | `spacingXs` | 紧凑间距 |
| sm | 8px | `spacingSm` | 小间距 |
| md | 16px | `spacingMd` | 标准间距 |
| lg | 24px | `spacingLg` | 大间距 |
| xl | 32px | `spacingXl` | 超大间距 |

### 圆角系统

| 级别 | 尺寸 | 变量名 | 用途 |
|------|------|--------|------|
| sm | 4px | `radiusSm` | 小元素 |
| md | 8px | `radiusMd` | 卡片、按钮 |
| lg | 12px | `radiusLg` | 弹窗 |
| xl | 16px | `radiusXl` | 大型容器 |

## 组件规范

### 窄侧边栏

```
┌──────┐
│ 头像 │  ← 用户头像/设置入口 (40x40)
├──────┤
│  📥  │  ← 收集箱
│  ☀️  │  ← 今天
│  📅  │  ← 最近7天
│  📆  │  ← 日历
│  📝  │  ← 笔记
├──────┤
│  ⚙️  │  ← 设置（底部固定）
└──────┘
```

- 图标大小：24px
- 选中状态：琥珀色浅背景 + 琥珀色图标
- 悬浮状态：显示 tooltip

### 任务卡片

```
┌─────────────────────────────────────────┐
│ ▌ ○ 任务标题                    📅 今天 │
│ ▌   标签1  标签2                        │
└─────────────────────────────────────────┘
```

- 左侧优先级指示条：3px 宽
- 完成按钮：20x20 圆形
- 选中状态：琥珀色边框 + 浅背景
- 完成状态：文字灰色 + 删除线

### 笔记卡片

```
┌─────────────────────────────────────────┐
│ 📌 标题                          标签   │
│                                         │
│ 内容摘要...                             │
│                                         │
│ 3天前                                   │
└─────────────────────────────────────────┘
```

- 卡片尺寸：240 x 180
- 悬浮效果：微微上浮 + 阴影加深
- 置顶图标：左上角

## 动效规范

### 过渡时长

| 类型 | 时长 | 用途 |
|------|------|------|
| 快速 | 150ms | 按钮状态、hover |
| 标准 | 250ms | 面板展开、页面切换 |
| 慢速 | 350ms | 复杂动画 |

### 缓动曲线

- 标准：`Curves.easeInOut`
- 进入：`Curves.easeOut`
- 退出：`Curves.easeIn`

### 特色动效

1. **任务完成**：琥珀色圆圈从中心向外扩散
2. **拖拽排序**：卡片拖起时有琥珀色光晕
3. **详情面板**：从右侧滑入

## 响应式规则

| 窗口宽度 | 布局调整 |
|----------|----------|
| < 800px | 不支持（最小窗口限制） |
| 800-1000px | 隐藏详情面板，点击任务弹窗显示 |
| 1000-1200px | 详情面板可收起 |
| > 1200px | 完整四栏布局 |

---

## 无障碍要求

1. 所有图标按钮必须有 tooltip
2. 颜色对比度符合 WCAG 2.1 AA 标准
3. 支持键盘导航
4. 表单输入有明确的焦点状态
